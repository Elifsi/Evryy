# Product Requirements — Consumer Application

The Consumer Application is the user-facing flagship product for the **evrry** Super App ecosystem, developed by **Elifsi Technologies Private Limited**.

---

## 1. Product Vision

A voice-first, AI-native super-app where users can seamlessly discover, chat, order, book, pay, and communicate across everyday commerce and service verticals.

---

## 2. Core User Journeys

### Journey 1: AI Concierge Discovery & Ordering
1. User opens app and taps the Voice Orb or types in chat.
2. User states request: *"Find a top-rated sushi place open now and order spicy tuna rolls."*
3. Concierge queries catalog, validates availability, and displays structured recommendation cards.
4. User selects item; Concierge presents draft order summary with transparent fees.
5. User provides explicit authorization; payment is initiated and completed.

### Journey 2: Marketplace Exploration & Multi-Vertical Checkout
1. User browses Explore tab across categories: Food, Grocery, Retail, Hotels, Mobility, Services.
2. User filters by distance, rating, price, dietary preferences, or availability.
3. Cart collects items; checkout supports local payment methods (eSewa, Khalti, Fonepay, Cards).
4. User monitors real-time status and live map tracking.

### Journey 3: Social & Communications
1. User connects with friends/family via phone/username.
2. Secure end-to-end encrypted direct messaging.
3. HD peer-to-peer WebRTC voice and video calling.
4. Ephemeral photo stories and camera filters (Snap).
