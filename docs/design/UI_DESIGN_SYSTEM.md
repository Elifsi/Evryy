**Rules**
- Use the **supplied artwork**. Never retype the wordmark in Inter; the lettering is custom (the R glyphs are distinctive).
- **Clear space**: 2× the E-symbol stroke-block height on all sides (Observed in "Clear Space" panel: grid marked `2x`).
- **Minimum size** (Decision): horizontal wordmark ≥ 80 px wide (digital) / 20 mm (print); compact ≥ 64 px; symbol ≥ 16 px (use 16/20 px optimised export).
- **Backgrounds**: navy wordmark on white/very light surfaces; white wordmark on navy/blue/dark. Never on busy imagery without a scrim.
- **Prohibited**: re-colouring outside navy/white/blue, stretching, rotating, outlining, adding shadows/glows, rearranging the three E lines, placing the tagline in a different typeface, recreating with system fonts, cropping the symbol tile corners.

## 4. Shape Language

- **Rounded everywhere**: tiles 16–20 px, cards 16–20 px, buttons 14–16 px (pill-leaning but not fully round), chips full-round, sheets 24 px top corners (Observed rounded; numeric radii are Decisions).
- **Separation by tint, not shadow**: white cards on `#F8FAFC`, 1 px `border.default`. Shadows only for floating layers (bottom sheet, toast, nav).
- **Generous whitespace**: 20 px screen padding, 24 px between sections.
- **Light mode is primary.** The reference also shows a dark Home preview; no dark palette is specified → proposal in tokens is provisional.

## 5. Iconography

- **Observed**: simple blue **outline** icons (chat bubble, card, wallet, person, bag, paper-plane, grid, document, heart, dots) inside **white/very-light rounded-square tiles** with a thin border.
- **Decision**: one library only — **Lucide** for web/prototype (already in repo), and its closest native equivalents on Android (Material Symbols *Outlined*, weight 400) / iOS (SF Symbols *regular*, outline variants). Do **not** mix styles or use emoji.
- Sizes: 16 / 20 / **24 (default)** / 28; stroke ≈ 1.75 px at 24; tile container **56 px**, icon 24–28 px centred; label 8 px below.
- States: unselected = `text.secondary` outline; selected = `brand.primary` (bottom-nav selected icon may be **filled**; everywhere else outline only).
- Every nav icon carries a **text label**.

## 6. Navigation model

See [`UI_SCREEN_SPECIFICATIONS.md`](UI_SCREEN_SPECIFICATIONS.md#navigation). Primary bottom nav is for top-level destinations; the Home shortcut grid is for services. A destination appears in only one place unless documented.
